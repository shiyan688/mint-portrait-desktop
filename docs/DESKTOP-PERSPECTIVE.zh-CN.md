# 手动四角透视：Desktop 0.2.9 候选

这是传统手动几何矫正，不是自动镜头校正、AI 修复或 SOTA 人像修图。没有新增模型、联网照片处理或付费服务。0.2.8 的发布目录和已交付安装包保持不变。

## 操作

1. 导入照片，右侧在“任意角度调平”之后找到“四角透视”区域，点击“编辑四角”。
2. 等待输入画面就绪。依次选择左上、右上、右下、左下，在画布点击或拖动设置当前角点；也可直接填写横纵百分比。角点相对裁剪/旋转/调平后的图像边界，不是原始文件坐标，也不是像素中心。
3. 输出宽、高百分比分别相对整个调平后画面。界面显示所选原图/工作基准的实际输出尺寸，不根据四边形自动猜宽高比。
4. 点击“应用透视”才加入一个可撤销步骤。“取消四角输入”、Esc、失焦、切换照片、切换输出基准或退出会丢弃未应用草稿，不改已提交照片。拖动取消只恢复该次拖动前的草稿。
5. 可以撤销、重做或明确“重置透视”。开启后，上游裁剪/90°旋转/翻转/任意角调平须先重置透视才能更改，避免旧角点被解释到另一个坐标系。

交叉、凹形、近退化的四角以及无效数字会拒绝，不会自动排序或替用户修成另一个区域。默认没有透视操作；中性配方保持输入字节，整像素裁切使用精确复制，其他情况需要重采样。

## 编辑顺序与保护

原图坐标人像、手动修补/液化、局部颜色等 → 锐化 → 裁剪/90°几何 → 调平 → 四角透视 → 留白 → 图片贴图 → 文字 → 绘画 → 遮盖 → 可选最终缩小 → 编码。

- 原图 Blob 和原图坐标编辑不重写。参考原图使用同一构图/调平/透视，但不带调色修图。
- 最终图片、文字、绘画、遮盖不会跟随照片一起做透视变形。图片和文字按其最终画布布局重排。
- 已有绘画/遮盖与几何配方绑定。修改或重置透视会拒绝，包含隐藏/空层；不会挪动、清空或偷偷更新绑定。需用户明确清除或撤销相关层后再改变几何。
- 源图选区仍可用于原图坐标工具。本版不支持把源图选区捕获到最终绘画/遮盖层后再和透视并用，隐藏/空/透明/仅橡皮层也不例外。该组合在分配画布或栅格化选区前拒绝，不对蒙版做未经验证的插值。
- 命名调色预设和跨片参数同步不复制透视；每张照片保留自己的几何。未应用角点不会保存进工程、恢复草稿或导出。

## 尺寸、颜色和重采样

仍为 8 位 sRGB 工作区，不是 RAW/16 位处理。原图处理保持原有最高 64,000,000 源像素预算，预览/工作尺寸与各工具还有更严格的边长、像素、内存与工作量限制；开启文字、贴图、绘画、遮盖等时通常有 16,777,216 最终处理像素限制。原图过大不会靠最后裁剪或缩小绕过，需明确选择工作尺寸并检查成品。

透视使用线性光、预乘 alpha 的有界各向异性 mip 重采样。透视会软化纹理，极端缩小/斜切可能更明显，不能声称无损；构造整数边界存在已披露的浮点量化边界。不同分辨率预览不保证与原尺寸结果逐像素相同。PNG 输出清理完全透明像素的隐藏 RGB，原图和工程仍保留原件。

导出核对冻结的配方、处理尺寸、透视前后尺寸和采样声明；缺失、错配或同尺寸不同四角结果不能写文件。最终缩小发生在所有最终层之后。

## 工程和验证范围

工程写 v17，读取 v1–v16；旧工程在当前、已提交、撤销、重做和最近导出等快照补 perspective:null，原图、连续浮点蒙版缓存及图片素材保留。真正的 v16 历史文件回读和重新编码负控已测。v17 缺失字段拒绝；旧版本文件携带活跃的未来透视字段拒绝。保存后的 v17 不能交给 v16 或更早程序读取，建议另存备份。手机工程格式不互换。

验证包括纯像素、实际像素 Worker 脚本、当前 app 事件在编写的 DOM/IPC 测试壳中运行、安装于云端的 NativeCanvas，以及真实 Sharp PNG 编码/解码。400×300 自制倾斜网格通过实际 app 应用和导出为300×240，同一输入尺度的预览与解码 PNG RGBA 完全相同，原件不变。另测调平、留白、文字/绘画/遮盖、最终缩小及不同处理尺度。
