# 当前可交付内容与差距：2026-10-22

## 分清三个层次

- 已交付的 0.2.8 开发版仍保留原文件与入口。新增 0.2.9 是独立未签名候选，不是已经完成 Windows 验收的正式版，也不是“像素蛋糕/醒图全部功能已完成”。
- 本轮真实新增手动四角透视，具备明确应用/取消、撤销、工程保存、原图/工作基准导出，以及与源选区、绘画、遮盖的冲突保护。3196 项回归通过，包含实际像素和 PNG；不是3196项独立产品功能。
- 公开竞品盘点的103项是验收工作包，不是已经逐项实现或验收的103个功能。历史清单的状态时间各异，不能用其旧快照替代本轮证据。

## 已有可执行的桌面编辑路径

本地导入、文件条及评分/筛选、原图/结果与双片参考比较；非破坏工程、撤销/重做、可选本地恢复草稿；原图保留及有界原尺寸/工作尺寸批量导出；基础调色、白平衡取样/明暗、色阶、曲线/分色HSL、局部调色、命名预设；传统人像调节及最多5人显式逐人选择；画笔/套索选区、推形/还原、取样修补/克隆、绘画/橡皮、马赛克/不透明遮盖；裁剪/90°旋转/翻转、任意角调平、锐化、留白、可编辑文字和本地图片贴图。新透视在0.2.9候选中。

每项仍有自己的像素、边长、工作量、绑定和内存边界。照片主处理为8位sRGB，不能把原件保存或原尺寸导出说成16位RAW管线。系统字体可能使不同系统排版不同。极值调色、锐化、形变、透视都不代表自然人像默认设置。

## 不能宣称已完成的部分

1. Windows 本机安装、启动、GPU/4060速度、缩放/字体/鼠标实际交互和卸载；真实 Chromium/Electron 窗口布局也未验收。云端 NativeCanvas 与编写的 DOM/IPC 测试不是实际浏览器。
2. 达到用户所要求的 SOTA 人像修肤、去瑕保纹理、妆容和整体美感。现有美颜/修补/形变为传统可调处理，不能因使用学习型人脸分析就叫学习型修肤。未经许可或有门槛的新模型没有偷偷执行。
3. SegFace 与 BiRefNet 已做获准的公开样片云端 CPU 推理，但不是用户4060实测或随当前Setup完整交付的GPU模型环境。BiRefNet样片仍暴露衣物漏抠、半透明残片和边缘光晕；传统前景颜色估计只能减轻部分色边，不能修正主体语义。
4. 高位深RAW/可靠完整颜色管理、专业镜头/镜头畸变校正、自动透视、充分验证的复杂发丝与服装抠图、多脸复杂重叠及全身塑形等。
5. 生成式重绘/消除/AI恢复/付费API的真实质量验收。部分后端仅是默认关闭的适配和模拟测试，不是已接通服务。没有使用用户照片或付费额度。
6. 联机拍摄、完整商业影楼选片交付、云协作、打印排版等完整产品工作流，以及竞品全量功能的独立对照验收。

手机另有一些已验证的共享候选核心，未自动并入桌面，例如膨胀/收缩/旋转液化和逐人美颜保护。没有把存在源文件当作桌面功能已完成。

## 本轮停止点

完成透视回归、可视证据、独立候选安装器与可恢复源码检查点后，暂停新增大模块，等待整体检查/下一步优先级。未完成项目保持明确，不靠增加空控件、模型名称或测试数量冒充验收。
