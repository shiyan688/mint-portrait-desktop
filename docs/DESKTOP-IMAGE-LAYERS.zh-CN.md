# 桌面本地图片贴图，0.2.8 候选

## 使用

1. 导入主照片，在右侧展开“本地图片贴图”，点“从本机导入图片层”。仅本机文件选择，不上传照片。
2. 编辑名称、位置、大小、旋转、透明度和翻转，或点“在画布点选中心”后点最终画布。大小是素材长边占最终画布短边的比例；超出画布裁切。
3. 点“应用贴图”才提交一次可撤销编辑。待应用输入、未完成导入均不进入照片、工程或导出。“取消输入 / 导入”、Esc 或切换照片不会偷偷提交；切换其他画笔会取消点选中心手势，保留输入供明确应用或取消。
4. 图层列表支持重编、显示/隐藏、上移/下移、移除，最多4层。更换主照片或其原件/修订时，旧异步导入拒绝提交。导出不等待或偷偷接受草稿。

## 顺序、预算与质量边界

照片编辑 → 构图 → 任意角调平 → 留白 → 图片贴图 → 文字 → 绘画 → 马赛克/不透明遮盖 → 可选输出缩小 → 编码。原图、原坐标手动工具和白平衡取样视图排除贴图，避免把它当作原始照片取样。

- 单帧 JPEG/PNG/WebP，编码≤32MiB、原素材≤24MP及8192边；拒绝动画和越界数据。
- 导入转为最长1024像素、最多1MP、8位sRGB RGBA工作素材。不保留原素材编码字节、路径或EXIF；有ICC时转换，没有ICC不猜测未知原色域。主照片原始编码字节仍完整保留。
- 每张照片最多16份、32MiB原始RGBA资产，全会话/工程最多128份、64MiB。当前、已提交、撤销、重做和最近导出状态引用的素材都保留；不把素材塞进每个历史快照。名称也保存在工程中。
- 启用贴图时最终处理画布≤16,777,216像素/16384边，图层累计分配≤256MiB，整体保守缓冲预算≤512MiB，另有计算量限制。复杂组合会更早拒绝。先按原处理源检查，后续缩小不能绕过；超限要明确选择“工作尺寸 · 明确缩小”。
- 核心使用编码sRGB域的预乘alpha、面积mip和边缘多采样合成，不是线性光合成或AI超分。小素材放大会变软，不保证跨分辨率逐像素相同。

## 历史、工程与隐私

工程写v16并读取v1–15，旧工程补空贴图/资产，不丢旧编辑；旧软件不能打开新工程。资产由SHA-256校验，RGBA blob每张照片去重；当前及所有历史引用必须可解。命名调色预设和跨片参数同步不携带资产，保留各目标照片自己的贴图。

工程、撤销历史和可选恢复草稿包含原图及工作素材，隐藏/移除不等于安全删除。不要把工程当作已脱敏成品。只分享逐张检查过的导出图片；马赛克不是可靠匿名化。
