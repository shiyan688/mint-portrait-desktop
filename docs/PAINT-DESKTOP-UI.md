# 未发布桌面绘画增量，checkpoint 19

此文档对应当前开发源码，不是已经交付的 0.2.5 安装包。使用传统 Canvas 画笔和显式覆盖率擦除，不是学习模型、SOTA 修图或可靠脱敏功能。未做 Windows / Chromium / Electron 交互验收。

## 操作

右侧“绘画与橡皮”展开后选择画笔、橡皮或取色。画笔大小为最终画布短边的 0.2%–12%，支持颜色与透明度；取色读取当前已接受的 8 位预览，不声称 RAW/显示器校准值。拖动、松开完成一笔，一笔对应一次撤销。Esc、取消、工具/照片切换、失焦、第二触点进入和导出会丢弃未完成笔迹。多触点必须实际全部释放后才能开始下一笔；丢失捕获不是释放事件。

最多四层，列表顺序从底到顶。可以选择层、显示/隐藏、上移/下移、删除层或全部清除。“下一笔新建层”不会立即写入空层，只让下一次画笔提交时创建。橡皮只减当前绘画层透明度，不擦原照片、文字、其他绘画层或遮盖；无已画图层时拒绝橡皮，不制造白色假擦除。

新层可以捕获当前手动选区，包含羽化权重。旧层始终使用创建时的选区快照，选择旧层时该复选框锁定；后来修改当前选区不会改旧层。若要采用新选区，显式新建层。选区属于未构图的源坐标，通过同一整数裁剪/90度旋转/翻转与留白变换，留白区域不自动纳入源选区。选择有形变的图像时，不能假装旧选区与新几何准确对应，相关组合明确拒绝。

## 顺序与历史

照片调节/局部/手动工具 → 构图 → 留白 → 文字 → 绘画 → 马赛克/不透明覆盖 → 最终尺寸调整 → 格式编码。

绘画是最终画布上的独立透明层。现有文字在下，遮盖在上；改变更早的构图、留白或形变前，需要撤销或清除受绑定的图层，不会默默移动笔迹。原图比较和上游取样不带绘画，但不会清除配方。照片间同步和命名调色预设不携带笔迹或选区，保留每张目标自己的绘画状态。原件始终独立，修改笔迹或撤销不重写照片字节。

工程写 v12，读取 v1–11 时中性迁移 paintLayers:null。新版本每个当前/提交/撤销/重做/导出设置槽位都校验绘画与源/几何绑定；保存配方而不是临时像素栅格。旧安装版可能拒绝新格式，请保留旧工程副本。项目和恢复草稿仍含原图和历史，不能当作已清除私人内容的导出副本分享。

## 预算和导出

绘画最终工作画布最多 16,000,000 像素、单边 16,384；总计最多128笔、8192点，每笔最多1024点。另有整组擦除/工作量和额外缓冲预算。最终缩小不允许绕过绘画处理画布预算；不自动降采样。源选区本身也须满足16M预算；无选区时，大原图可以先在合法主流水线中裁小，再绘画。

真实导出接收独立 paintOverlay，绑定原始压缩字节哈希、源版本、配方哈希、请求ID、尺寸和工作/原尺寸模式。取消、过期、异尺寸或缺失像素均拒绝，没有无声丢画替代。PNG全透明像素在最终导出时清零隐藏RGB；JPEG末尾白底并重编码。源文件本身与工程中的原字节不清除、不覆写。

Canvas抗锯齿、颜色取整与操作系统图形后端可能有差异。纯/NativeCanvas回归不等于Windows同像素。大尺寸分块擦除对全画布参考的AA边界在一个样例中最大差33/255，平坦内部和跨块内部精确；33不是普遍上限。逻辑缓冲预算不是进程RSS上限。应用在每层native渲染前后让出事件循环、释放中间画布并检查取消，不无限连续同步渲染。
