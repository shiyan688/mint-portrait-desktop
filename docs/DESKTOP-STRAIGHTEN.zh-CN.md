# 任意角度调平：0.2.7开发版

本模块包含于0.2.7开发版Setup；以下云端检查不等于真实Windows、Chromium GUI或显卡性能验收。传统几何重采样不属于 SOTA 人像修图。

## 如何使用

在右侧“任意角度调平”输入 -180 至 180 度，正数顺时针。选“扩展透明画布”保留旋转后完整内容，或选“居中裁切”去除旋转产生的边角。先查看预计尺寸，再点“应用调平”。输入数值本身不改变画布、历史或导出；取消、Esc、切换照片/工具、保存或开始导出会丢弃未提交草稿。

应用记录一个可撤销步骤。重复应用完全相同的配方不会新增历史。“重置调平”只清除这一项，不移除之前的调色和构图。原始文件字节始终保留；工程 v14 保存可编辑角度及各历史快照，并读取 v1–13。旧程序不能打开新工程，请保留旧工程副本。

有非零调平时，旧的裁剪、90度转向、翻转和构图重置按钮暂时禁用，避免改变两套坐标规则。需要重新构图时，先重置调平，再构图，再应用角度。已有绑定到最终画布的绘画/遮盖层可能阻止这种变更；必须明确撤销或移除有关图层，程序不偷偷删除、挪动或重新绑定它们。

## 处理顺序与对比

原图空间调色、人像、蒙版和手工修饰 → 既有构图 → 调平 → 留白 → 文字 → 绘画 → 马赛克/遮盖 → 最终缩小输出。

原图/结果对比使用完全相同的构图、调平与留白，因此不会把旋转几何差异当作修图前后效果。匹配原图由独立的可取消任务生成；还没完成时不显示错误角度的旧图。换图、撤销、快速改角度及旧任务晚到均不能覆盖新结果。需要原图空间的选区、修复、人物检查等工具显示未调平的源空间；回到结果视图才显示最终几何。

新绘画/遮盖可以在最终画布进行，但带有原图选区快照的图层只支持精确 90 度倍数。任意其他角度明确拒绝，包括隐藏、禁用或空的选区绑定层。这里不会把浮点蒙版的二进制字节当颜色插值，也不会默默取消选区。

## 像素与资源边界

- 零角度严格中性。精确 90 度倍数采用逐像素复制；纯核心保留 RGBA 和隐藏 RGB。照片解码与 Canvas 内部表示仍遵循各平台行为，不能据此承诺跨平台隐藏 RGB 一致。
- 其他角度采用线性光、预乘 alpha 的双线性重采样。扩展模式出现的透明像素不会混入隐藏背景色；PNG 导出将完全透明像素的 RGB 清零，JPEG 在末尾铺白底。
- 居中裁切采用连续几何中的最大中心内接矩形，再向下取整，不缩放补回原尺寸。它不承诺在整数像素格中求得面积最大的其他矩形。
- 非精确的极小角度或接近 90 度的角度仍会执行重采样，可能增加一行/列、产生半像素相位和轻微软化；没有悄悄吸附到整数角。边界尺寸使用 binary64 运算，构造出的整数临界值可能相差一个像素。界面会显示实际计划尺寸。
- 原尺寸链仍有既有 6400 万像素/16384 单边上限，带最终画布图层另有限制；调平再受 512 MiB 保守受控缓冲区预算约束。不是所有上限内照片都能执行所有角度。计划将非空的中性构图、零边留白等实际分配也计入，并计入当前仍保留的画布。该预算是静态准入估计，不是实测进程峰值内存保证。
- 调平、留白和图层之后才缩小导出。把最终输出设小不能绕过源图和中间画布预算。超限会明确拒绝，不自动降低原图处理尺寸。
