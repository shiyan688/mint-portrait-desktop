# Independent current-app image-layer event proof

This folder's `app-*` artifacts are generated by `tests/image-layers-ui-independent.test.cjs` against the current production `src/app.js`, `image-layer-panel.cjs`, session/codec/queue code and native export renderer. No production app logic is replaced. The authored test DOM/IPC shell is adapted from the existing text/paint test harness; the preview bridge executes the real shared export pixel core and installed NativeCanvas, and final PNG exports execute the real Sharp worker through `createExportRenderer`.

These are synthetic-only integration and pixel-output checks. They are not browser layout, native dialog, Electron GUI, Windows installer, user-machine, private-image, or model-inference evidence.

Run from the source directory:

```
node --test tests/image-layers-ui-independent.test.cjs
```

No dependencies are installed. NativeCanvas is loaded from the already-installed runtime path; Sharp is the existing app dependency. Missing NativeCanvas fails the harness rather than silently skipping tests.
