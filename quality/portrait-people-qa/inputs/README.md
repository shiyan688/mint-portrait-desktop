# Reproducible local inputs

These two PNGs and landmark JSON files are byte-identical copies of the previously recorded public NASA adult synthetic-composite host fixtures. host-inference-evidence.json carries exact source URLs, credit, adult evidence, model/runtime provenance, input/output hashes and limitations. No fresh inference was run to package them.

Only private informational QA is intended. Not real group photographs; not model training, advertising, stock content, app assets, person endorsement or commercial portrait permission. NASA media guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/

The test helpers default to this repository-relative directory. The PNGs belong in the separate QA archive, the JSON/readme in the source overlay. Both archives are required to reproduce these tests. Production packaging excludes quality/ and tests/.
